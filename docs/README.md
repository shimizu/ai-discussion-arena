## 30秒で把握する概要

- React 19 + Vite 8 の完全なブラウザアプリで、バックエンドはありません。
- ブラウザから Anthropic Messages API、OpenAI Responses API、Gemini `generateContent` を直接呼び出します。
- 討議エンジンは「議長・肯定側・否定側」をAIプロバイダーへ割り当て、共有議事録を毎ターン渡します。
- LLMが必要と判断すると、e-StatまたはWorld Bankの取得ツールを関数呼び出しし、結果を全参加者へ共有します。
- APIキー、モデル設定、直近の討議記録は `localStorage` に保存されます。サーバー側保存、認証、複数討議の履歴管理はありません。
- 本番ビルドだけCSPが注入されます。接続先を増やすときは `vite.config.js` の `CONNECT_SRC` 更新が必須です。

## 重要な設計上の不変条件

保守時は、次の契約を崩さないでください。

1. `src/discussion/` はベンダー固有のAPI形式を扱わない。
2. LLMのツール往復は1発言の内部で完結させる。
3. アシスタント応答の `raw` は再構成せず、そのまま同じベンダーへ返す。
4. ツール定義は `src/tools/tool-defs.js` の中立形式を唯一の定義元にする。
5. ツール結果は、LLM向け `content` とCSV向け `dataset` を分ける。
6. 保存データは `sanitizeSession()` を通してからUIへ渡す。
7. 外部接続先の追加時はCSPとテストを同時に更新する。

## 現時点の運用上の注意

- 既定モデルIDは実キーでの疎通未確認です。初回運用では必ず「一覧を取得」で利用可能モデルへ設定してください。
- APIキーは暗号化されず `localStorage` に保存されます。共有端末や信頼できないスクリプトを含む配布形態には向きません。
- 中断した討議は復元できますが、続きからの再開はできません。
- 保存できるのは直近の1討議だけです。新しい討議を始めると前回記録を削除します。
- `dist/` は生成物です。ソース変更後は `npm run build` で作り直し、直接編集しないでください。
